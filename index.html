나쁜 표본추출과 편향 How to sample badly

Bias: 표본 설계가 모집단의 어떤 부분을 체계적으로 과대 또는 과소 대표해서 결론이 현실을 반영하지 못하는 상태.

종류뜻예

Convenience가장 만나기 쉬운 사람을 고름. 쉽게 닿는 것은 대표하는 것이 아님급식실 앞 지나가는 학생

3.3

좋은 표본추출: Random sampling

편향의 근본적인 해결책은 무작위 추출입니다. 우연으로 선택되면 어떤 집단도 체계적으로 유리하지 않습니다.

Sampling variability

같은 모집단에서 뽑은 서로 다른 무작위 표본은 서로 다른 statistic을 만든다. 무작위 추출의 피할 수 없는 결과.

Sampling error

표본 statistic과 실제 parameter의 차이. 결함이 아니라 표본만 관찰하는 데서 오는 자연스러운 결과.

핵심sampling variability와 sampling error는 예측하고 수량화할 수 있지만 bias는 그렇지 못합니다. 표본 크기를 키우면 variability는 줄지만 bias는 사라지지 않아요.

영어 답안 템플릿 (KMLA 450명 → 30명)

SRS

"Label all 450 students 001 to 450. Starting at a randomly chosen place in the random digit table, read three-digit numbers from left to right. Select the student whose label matches each number from 001 to 450. Skip numbers greater than 450, 000, and any repeats. Continue until 30 different students have been selected."

Stratified

"Divide the students into three strata by grade, since students in the same grade are similar. Within each grade, label the students 001 to 150. Using the random digit table, select an SRS of 10 students from each grade (skipping numbers above 150 and repeats). Combine the three groups to get the 30 students."

Cluster

"The 450 students are in 30 homerooms of 15 students (each homeroom is a cluster). Label the homerooms 01 to 30. Using the random digit table, read two-digit numbers and select 2 different homerooms (skipping numbers outside 01–30 and repeats). Survey every student in the 2 selected homerooms."

Systematic

"Label the students 1 to 450. The sampling interval is k = 450/30 = 15. Use the random digit table to choose a random starting number between 01 and 15. If the start is 7, select students 7, 22, 37, …, every 15th student, until 30 students are selected (the last is 442)."

Understanding Probability

확률은 사건이 일어날 가능성을 나타내는 수치이고, 다음을 만족합니다.

확률의 조건

  • 0 ≤ P(A) ≤ 1
  • 불가능한 사건(impossible): P(A) = 0
  • 반드시 일어나는 사건(certain): P(A) = 1

두 가지 관점

  • Theoretical P(A) = A에 속한 결과 수표본공간의 전체 결과 수
  • Empirical P(A) = 처음 n번 중 A가 나온 횟수전체 시행 횟수

The Law of Large Numbers 시험 안 나옴 (참고)

독립이고 같은 분포를 따르는 시행을 계속 늘리면, 사건의 상대도수가 진짜 확률에 가까워집니다. Xi = 1(i번째에 A 발생), 0(아니면)이라 하면 pn = 1n Σ Xi.

Weak LLN

limn→∞ P(|pn − p| > ε) = 0

n이 커질수록, 정해 둔 오차 ε보다 크게 벗어날 확률이 0으로 갑니다.

Strong LLN

P(limn→∞ pn = p) = 1

확률 1로, 관측된 상대도수의 수열 자체가 p로 수렴합니다.

동전 던지기 시뮬레이터
The Gambler's Fallacy독립적인 무작위 과정에서 과거 결과가 "균형을 맞추는" 결과를 더 잘 나오게 만든다고 믿는 오류. 앞면이 5번 연속 나와도 다음 번 뒷면 확률은 여전히 12입니다. LLN은 "장기적으로" 수렴한다는 말이지, 짧은 구간에서 보정해 준다는 말이 아닙니다.

Conditional Probability 조건부확률

조건부확률은 다른 사건이 이미 일어났다는 것을 알 때 한 사건이 일어날 확률입니다. P(B) > 0일 때 다음과 같이 정의합니다.

P(A|B) = P(A∩B)P(B)

P(A|B)는 "B가 일어났다는 조건에서 A의 확률"로 읽습니다. 다른 말로, 표본공간을 B로 제한하고 B 안에서 A에도 속하는 결과의 비율을 구하는 것입니다.

곱셈 법칙식을 정리하면 P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A). A와 B가 동시에 일어날 확률을 구하려면 먼저 조건부확률부터 구해야 합니다.
주의P(A|B)와 P(B|A)는 보통 다릅니다. 뒤의 병 검사 예제에서 P(양성|병) = 0.95인데 P(병|양성)은 0.107밖에 안 돼요.

예제 1 · 퓨즈 상자

퓨즈 20개 중 5개가 불량. 3개를 비복원으로 뽑을 때 셋 다 불량일 확률은? (Dn = n번째가 불량)

P(D1∩D2∩D3) = P(D1)·P(D2|D1)·P(D3|D1∩D2)
= 520 × 419 × 318 = 1114 ≈ 0.0088

조합으로 검산: 5C3 / 20C3 = 10/1140 = 1/114.

예제 2 · 양말 서랍

검정 4, 갈색 6, 올리브 8켤레(총 18). 2개를 뽑는다.

  • (a) 같은 색일 확률 = (4C2+6C2+8C2) / 18C2 = (6+15+28)/153 = 49/153 ≈ 0.320
  • (b) 같은 색인 것을 알 때 둘 다 올리브일 확률 = P(둘 다 올리브)P(같은 색) = 28/15349/153 = 4/7 ≈ 0.571

(b)는 "둘 다 올리브"가 "같은 색"에 포함되므로 교집합이 그대로 28/153입니다.

3-1

Independence 독립과 disjoint는 다름!

두 사건 A, B는 한쪽이 일어나도 다른 쪽의 확률이 변하지 않을 때 독립입니다. P(B) > 0일 때 아래 세 가지는 모두 같은 말입니다.

P(A|B) = P(A)  ⇔  P(B|A) = P(B)  ⇔  P(A∩B) = P(A)·P(B)
Independent (독립)Disjoint (배반)
조건P(A∩B) = P(A)P(B)A∩B = ∅, 즉 P(A∩B) = 0
뜻A가 일어나도 B의 확률이 안 변함A가 일어나면 B는 절대 못 일어남
관계확률이 0이 아닌 두 사건은 독립이면서 동시에 배반일 수 없습니다.

참: disjoint인 두 사건은 항상 종속

(단, 두 확률이 0이 아닐 때) P(A∩B) = 0 이지만 P(A)P(B) ≠ 0 이므로 P(A∩B) ≠ P(A)P(B). 따라서 독립이 아닙니다. 한쪽이 일어나면 다른 쪽이 못 일어나니 서로 영향을 주는 거예요.

참: A, B가 독립이면 Ac와 B도 독립

P(Ac∩B) = P(B) − P(A∩B) = P(B) − P(A)P(B) = P(B)(1 − P(A)) = P(B)·P(Ac)

같은 방법으로 A와 Bc, Ac와 Bc도 독립입니다.

예제 3 · 적어도 하나

A, B가 독립, P(A) = 0.4, P(B) = 0.3일 때 둘 중 적어도 하나가 일어날 확률은?

P(A∩B) = 0.4×0.3 = 0.12
P(A∪B) = 0.4 + 0.3 − 0.12 = 0.58

검산: 1 − P(Ac)P(Bc) = 1 − 0.6×0.7 = 0.58

예제 4 · 카드 5번 뽑기

52장에서 1장 뽑고 다시 넣기를 독립적으로 5번. 스페이드 에이스가 정확히 4번 나올 확률은, 적어도 4번 나왔다는 조건에서?

A = 정확히 4번, B = 적어도 4번. A ⊂ B 이므로 P(A|B) = P(A)/P(B).

5C4(1/52)4(51/52) ÷ [5C4(1/52)4(51/52) + (1/52)5] = 5·51/(5·51+1) = 255/256 ≈ 0.996

Bayes' Theorem P(B|A)를 구할 때

P(B|A) = P(B∩A)P(A) = P(A|B)·P(B)P(A)

표본공간 S가 사건 B1, …, Bn으로 쪼개져 있고, 두 조건을 만족하면 partition(분할)입니다. 피자 조각 자르듯이

  • Disjoint: i ≠ j이면 Bi ∩ Bj = ∅ (겹치는 조각 없음)
  • 합이 전체: B1 ∪ B2 ∪ ⋯ ∪ Bn = S (빠진 조각 없음)

그러면 어떤 사건 A의 확률은 조각별로 나눠서 더할 수 있고(전체확률의 법칙), 이것이 베이즈 공식의 분모가 됩니다.

P(A) = P(A|B1)P(B1) + ⋯ + P(A|Bn)P(Bn)
P(Bi|A) = P(A|Bi)P(Bi)P(A|B1)P(B1) + ⋯ + P(A|Bn)P(Bn)
풀이 순서① 조각(Bi)과 관찰한 사건(A)을 정한다 ② P(Bi)와 P(A|Bi)를 전부 적는다 ③ 분모 = 모든 조각의 P(A|Bj)P(Bj)를 더한 값 ④ 구하려는 조각의 항을 분모로 나눈다.

P(D|T) = 0.95×0.010.95×0.01 + 0.08×0.99 = 0.00950.0887 ≈ 0.107

조각: D(병), Dc(건강). 양성이어도 진짜 병일 확률은 약 10.7%.

The Monty Hall Problem 시험에 나옴!

시험 변형 주의필기에 "시험에 나옴, 문 n개와 차 n개를 바꿔서 나올 수 있음"이라고 적혀 있습니다. 문 개수, 차 개수, 호스트가 여는 문 개수를 바꿔도 풀 수 있게 일반식까지 정리했어요.

① 기본: 문 3개, 차 1대

참가자가 1번 문을 고르고, 정답을 아는 호스트가 2번 문을 열어 연필을 보여줬다. 3번 문으로 바꾸면 차를 얻을 확률은? Ci = 차가 i번 문 뒤, O2 = 호스트가 2번 문을 열어 연필이 나옴.

차의 위치P(Ci)P(O2|Ci)이유
C11/31/22, 3번 모두 연필 → 호스트가 둘 중 무작위
C21/302번에 차가 있으면 열 수 없음
C31/313번에 차가 있으면 2번을 열 수밖에 없음
P(O2) = 12·13 + 0 + 1·13 = 12  ⇒  P(C3|O2) = P(O₂∩C₃)P(O₂) = 1/31/2 = 23

유지하면 P(C1|O2) = (1/6)/(1/2) = 1/3. 그래서 바꾸는 게 유리합니다.

② 문 10개, 차 3대

호스트(정답을 앎)는 참가자가 고른 1번 이외의 문 중 연필이 든 문을 모두 같은 확률로 하나 골라 엽니다. 호스트가 2번 문을 열어 연필이 나왔을 때, 차가 8번 문 뒤에 있을 확률은? 1번과 8번의 차 유무로 4칸으로 나눕니다.

경우P(경우)P(O2|경우)곱
C1∩C83/10 × 2/9 = 1/157/8 × 1/7 = 1/81/120
C1c∩C87/303/4 × 1/6 = 1/87/240
C1∩C8c7/303/4 × 1/7 = 3/281/40
C1c∩C8c7/155/8 × 1/6 = 5/487/144
  • P(O2|경우)는 (2번이 연필일 확률) × (호스트가 그 연필 문을 고를 확률)입니다. 예를 들어 C1∩C8이면 나머지 차 1대가 남은 8개 문(2~7, 9, 10) 중 하나라서 2번이 연필일 확률은 7/8, 호스트가 열 수 있는 연필 문은 7개라서 1/7입니다.
  • 네 곱의 합: P(O2) = 1/120 + 7/240 + 1/40 + 7/144 = 80/720 = 1/9
  • 분자: P(O2∩C8) = 1/120 + 7/240 = 3/80
  • P(C8|O2) = (3/80)/(1/9) = 27/80 = 0.3375  vs  유지 P(C1|O2) = 3/10 = 0.3 → 8번으로 바꾸는 게 유리
노트 보완필기에는 각 칸이 9/100, 21/100, 49/100처럼 적혀 있는데, 이것은 각 문에 차가 있을 확률 3/10을 서로 독립으로 본 값입니다. 차가 정확히 3대이므로 비복원처럼 계산해야 하고(예: P(C1∩C8) = 3/10 × 2/9 = 1/15), 위 표가 정확한 값입니다. 노트에도 "3/10 × 2/9"가 써 있어요.

③ 일반식: 문 n개, 차 k대, 호스트가 m개를 열 때

참가자가 1번 문을 고르고, 호스트가 나머지 문 중 연필이 든 문 m개를 무작위로 엽니다. 열리지 않은 다른 문 하나를 지정했을 때 그 문에 차가 있을 확률은 대칭성으로 바로 나옵니다.

유지: kn    바꾸기: kn × n−1n−1−m = k(n−1)n(n−1−m)
  • 기본(n=3, k=1, m=1): 바꾸기 = 1/3 × 2/1 = 2/3 ✓
  • 10문·차 3대·m=1: 3/10 × 9/8 = 27/80 ✓
  • 이유: 8번에 차가 있으면(확률 k/n) 호스트는 1·8번을 뺀 n−2개 중 하나를 엽니다(2번을 열 확률 1/(n−2)). 호스트가 2번을 열 전체 확률은 1/(n−1). 그래서 (k/n)·(1/(n−2)) ÷ (1/(n−1)).
  • 바꾸는 쪽이 항상 유리합니다. (n−1)/(n−1−m) > 1 이기 때문이에요.
호스트가 정답을 모르면?호스트가 차 위치를 모르고 아무 문이나 열었는데 마침 연필이었다면 정보가 없어서, 3문 기본형에서 바꾸나 유지나 모두 1/2입니다. "호스트가 일부러 차를 피해 연다"는 조건이 핵심이에요.

What is a Random Variable? 확률변수

확률변수는 무작위 과정의 결과를 숫자로 나타낸 변수입니다. 변수는 대문자(X, Y), 그 변수가 가지는 구체적인 값은 소문자(x, y)로 씁니다.

예: 동전을 3번 던진다. X = 앞면의 수

X가 가질 수 있는 값: 0, 1, 2, 3. 각 값의 확률은 8가지 결과(HHH, HHT, …)를 세어 구한 것입니다.

x0123
P(X = x)1/83/83/81/8

확률을 전부 더하면 1/8 + 3/8 + 3/8 + 1/8 = 1 입니다. (표는 직접 계산해서 넣었어요.)

Discrete vs Continuous

(1) Discrete 이산(2) Continuous 연속
값셀 수 있는(countable) 값, 보통 정수구간 안의 모든 값(셀 수 없음). 보통 측정으로 얻음
예앞면의 수, 형제 수, 한 시간 동안 도착하는 차의 수키, 1마일 달리는 시간, 과자 봉지의 무게
기술 방법확률분포(값 목록과 각 확률)밀도곡선(density curve). 확률 = 곡선 아래 넓이
조건0 ≤ P(X = x) ≤ 1  그리고  Σ P(X = xi) = 1곡선 아래 전체 넓이 = 1
한 점의 확률값마다 자기 확률이 있음P(X = x) = 0

연속확률변수의 확률 = 넓이

P(a ≤ X ≤ b) = ∫ab f(x) dx

왜 한 점의 확률이 0인가

한 점에는 폭이 없으니 곡선 아래 넓이가 0입니다. 그래서 정확히 키가 170.00000…cm일 확률은 0이에요. 확률이 0이어도 불가능하다는 뜻은 아니고, 구간으로 물어야 의미가 있습니다.

같은 이유로 연속확률변수에서는 P(a ≤ X ≤ b) = P(a < X < b) 입니다. 끝점을 포함해도 넓이가 안 변해요.

μX = E(X) = Σ xi · P(X = xi)

Planning and Conducting Experiments

관찰연구(observational study)는 두 변수가 연관되어 있다(associated)는 것까지만 보여 줍니다. 연관은 인과가 아닙니다. 한쪽이 다른 쪽을 일으킨다고 주장하려면 실험이 필요합니다.

실험의 정의실험은 조건을 조작하고(manipulates conditions), 피험자를 그 조건에 무작위로 배정하고(randomly assigns), 그룹 간 반응을 비교합니다(compares responses). 인과적 결론을 뒷받침할 수 있는 유일한 설계입니다.

Principles of Experimental Design

(1) Control

처치 이외의 모든 변수를 그룹 간에 최대한 같게 유지. 그룹 사이의 체계적인 차이는 처치 하나뿐이어야 합니다.

(2) Randomization 가장 중요

실험 단위를 처치 그룹에 무작위로 배정. 알려진 것이든 아니든 confounding 변수가 우연에 의해 그룹 간에 고르게 퍼집니다.

(3) Replication

충분히 많은 피험자에게 처치를 반복 적용. 한 명의 특이한 피험자 때문에 생긴 우연한 차이가 아니라 진짜 차이가 보이게 합니다. 실험할 땐 subject가 충분해야 함

(4) Blocking — Reducing Variability

실험 단위들이 중요한 면에서 서로 다를 때(예: 성별에 따라 새 공부법 반응이 다름), 무작위 배정 전에 비슷한 단위끼리 묶어 잡음을 줄입니다.
