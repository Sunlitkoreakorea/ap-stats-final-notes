# AP 통계학 I · 기말 노트

AP Statistics I(2026-2학기) 기말고사 대비 학습 사이트입니다. 수업 프린트(Chap 3 자료 수집, Planning and Conducting Experiments, Chap 4 Probability)와 필기를 바탕으로 만들었습니다.

- **개념 정리**: 3장 자료 수집·편향·네 가지 무작위 추출법(필출: 추출법 적용, 영어 답안 템플릿), 실험 설계 용어·4원리·CRD/RBD 도식, 4장 경우의 수·확률 기호·큰 수의 법칙·확률 규칙, 조건부확률·독립·베이즈 정리·몬티홀(일반식, 변형 문제, 시뮬레이터), 확률변수·이산/연속·기댓값(계산기)
- **개념 검색**: 사이드바 검색창 또는 `Ctrl+K` / `/` 로 열기. 개념 문단과 용어 카드를 한·영 모두 검색하고, 결과를 열면 해당 위치로 이동해 강조
- **홈**: 단원별 진행률, 오답·별표 요약, 이어서 풀기
- **실전 모의고사 (OMR)**: AP 스타일 객관식 66문항 + 서술형 2문항(prob#1). 풀고 제출하면 내가 고른 답이 OMR 답안지에 마킹된 모습으로 나타나고, 채점하면 정답·해설·주제별 정답률 표시. 타이머 일시정지(P 키) 지원
- **문제 풀기**: Problem set #1 전체 풀이와 몬티홀 변형 문제 포함 117문항(객관식·T/F·답 입력·서술형), 즉시 채점·해설·오답만 보기
- **실험 설계도**: 시나리오별 CRD/RBD 도식 자동 생성, 빈칸 모드, 만점 체크리스트
- **용어 카드**: 51장, 외운 카드 표시
- 도구: 순열·조합 계산기, 동전 던지기(LLN) 시뮬레이터, 난수표 읽기, 베이즈 계산기, 몬티홀 시뮬레이터
